如何理解 0 分与 5 分

准确完整回答问题可以得 5 分，简短不影响满分；这些 0 分案例存在结论相反、顺序颠倒或答错对象。参考答案尚未全部人审，Judge 只比较文字语义，截图供读者理解案例。
