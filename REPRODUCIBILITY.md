# Reproducibility guide

This artifact supports three levels of inspection and reproduction.

## 1. Validate the frozen release

No model, media, API key, or third-party package is required:

```bash
python tools/validate_release.py
```

The validator checks the 450/900/1,250 task accounting, language and capability
counts, source manifest size, frozen task and rubric hashes, and common leakage
patterns in text files.

## 2. Recompute Judge scores

`judge/run_judge.py` accepts a standardized evaluation-result file and the
frozen rubric. It records the matcher model, prompt, score constants, token
usage, and raw matched responses needed for audit. The final numeric score is
computed locally rather than generated by the LLM. For MOSS, complete runtime
logs can first be passed through `tools/rematch_moss.py`; candidate responses
changed by the delivery-aware match must then be scored by the frozen Judge.

```bash
python -m pip install -r requirements.txt
export OPENROUTER_API_KEY="..."
python judge/run_judge.py \
  --eval /path/to/evaluation_results.json \
  --rubric judge/rubric.json \
  --out runs/model-judge
```

## 3. Rebuild analyses or run a model

The aggregate reports under `Experiment/` were generated from the archived run
tree. Analysis scripts and exact evaluator snapshots are preserved. Full model
execution additionally requires the authorized media archive, model weights,
model-specific Python environments, and optionally a Judge API key.

Configure required paths in the process environment using
`pipelines/10-20/env.example`. Do not write credentials into the repository.

The 1 FPS and 10 FPS snapshots remain separate. Raw scores from different
Judge profiles must not be interpreted as an FPS-only comparison.

## Included evidence

- frozen benchmark tasks and rubric;
- 1 FPS and 10 FPS aggregate result JSON;
- completeness, provenance, and checksum manifests;
- exact generation, evaluation, judging, and analysis snapshots;
- alternate-Judge, modality, context, forced-response, and state diagnostics;
- assisted-human-study aggregates and de-identified per-record scores;
- report sources and six SVG figures per completed experiment track where
  provided by the original snapshot.

## External evidence

The artifact does not include source videos, extracted frames, synthesized TTS,
model weights, local caches, credentials, or machine-specific run directories.
Those files are external controlled artifacts. The repository publishes their
identifiers, relative manifest paths, counts, and available checksums so they
can be validated when supplied under the applicable source rights.
